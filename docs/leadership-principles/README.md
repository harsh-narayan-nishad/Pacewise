# Leadership principles

How well-known leadership principles read when they are applied to building Pacewise. The headings follow each company's own published list, so they are easy to recognise and to use in interview answers. Every sentence underneath is original and written for this platform: its readers, its quizzes, its docs and its search.

- **[Amazon's Leadership](amazon/01-amazon-leadership-principles.md)**: sixteen principles, each with what it means for Pacewise.
- **[Google's Leadership](google/01-google-leadership-principles.md)**: ten principles, each with what it means for Pacewise.

## How to use these pages

1. Read the principle as a question about a real decision in the project, not as a slogan.
2. Use the "In Pacewise" lines as true examples: each one points at something that exists in the code or the docs.
3. In an interview, pick the example that fits the question, state the decision, the alternative you rejected, and what the result was.

## A note on sources

The company names appear only to say whose list a heading comes from. The principles are public, the wording here is not copied from them, and nothing on these pages is an official statement of either company.
