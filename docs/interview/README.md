# SDE Interview Prep — topic-wise (Easy / Medium / Hard)

Aimed at top-paying SDE roles (the ~₹2.5 Cr band: Staff-leaning SDE-2/SDE-3 at product and big-tech companies). At that level the bar is: **sound fundamentals, clean problem solving, and the ability to design and defend real systems.** Every topic below has Easy → Medium → Hard questions with short model answers, and ties back to code in this project so you can speak from experience.
