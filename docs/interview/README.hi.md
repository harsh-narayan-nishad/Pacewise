# SDE Interview Prep — विषय-वार (Easy / Medium / Hard)

यह सबसे अधिक वेतन वाली SDE roles (~₹2.5 Cr band: product और big-tech companies में Staff-leaning SDE-2/SDE-3) को ध्यान में रखकर बनाया गया है। इस level पर अपेक्षा है: **मज़बूत fundamentals, साफ़ problem solving, और असली systems को design करने व defend करने की क्षमता।** नीचे हर विषय में Easy → Medium → Hard प्रश्न छोटे model answers के साथ हैं, और वे इस project के code से जुड़े हैं ताकि आप अनुभव से बोल सकें।

उपयोग कैसे करें: उत्तर को ढक लें, अपना उत्तर ज़ोर से बोलें, फिर तुलना करें। हर Medium/Hard प्रश्न के लिए **trade-off** और **failure mode** भी बताएँ — यही senior उत्तरों को mid-level उत्तरों से अलग करता है।
